## 🚀 Getting Started

### Creating an Account

1. Click **"Get Started"** on the home page
2. Click **"Register"** 
3. Fill in:
   - Username (unique)
   - Email address
   - Password
4. Click **"Register"**
5. You'll be redirected to login

### Logging In

1. Click **"Login"** in the navigation menu
2. Enter your username and password
3. Click **"Login"**

## 🎵 Uploading Songs

### Step-by-Step Upload

1. Click **"Upload"** in the navigation menu
2. Fill in the song details:
   - **Song Title** (required)
   - **Select Genres** - Click genre tags to select multiple
   - **Audio File** - Click "Choose file" and select MP3, WAV, or AAC
3. Click **"Upload Song"**
4. Wait for the upload to complete
5. You'll see a success message when done

### Supported Formats
- ✅ MP3 (.mp3)
- ✅ WAV (.wav)
- ✅ AAC (.aac)

### Tips
- Keep file sizes reasonable (under 10MB recommended)
- Use clear, descriptive titles
- Select all relevant genres for better discoverability

## 🎧 Browsing & Playing Music

### Finding Songs

**Search:**
1. Go to **"Songs"** page
2. Type in the search box
3. Click **"Search"** or press Enter

**Filter by Genre:**
1. Type in the "Search genres..." box to find genres
2. Click genre tags to select them
3. Songs must have ALL selected genres (AND logic)
4. Click the **X** on active filters to remove them

**Sort Songs:**
- Songs are sorted alphabetically by default
- Use filters to narrow down results

### Playing Music

**Play Now:**
- Click the **"▶ Play Now"** button on any song
- The global player appears at the bottom
- Song starts playing immediately

**Add to Queue:**
- Click **"+ Add to Queue"** button
- Song is added to the end of the queue
- Continue browsing while music plays

### Using the Global Player

The player at the bottom of the screen has:
- **⏮ Previous** - Go to previous song in queue
- **▶/⏸ Play/Pause** - Toggle playback
- **⏭ Next** - Skip to next song
- **Progress Bar** - Drag to seek
- **Volume Slider** - Adjust volume (0-100%)
- **Queue List** - See and manage upcoming songs

### Managing the Queue

**View Queue:**
- Click on the queue section in the player
- See all songs in order

**Play from Queue:**
- Click on any song number or title in the queue

**Remove from Queue:**
- Click the **✕** button next to a song

**Clear Queue:**
- Click **"✕ Clear"** button to remove all songs

## 📝 Creating Playlists

### Create a New Playlist

1. Go to **"Playlists"** page
2. Click **"Create New Playlist"**
3. Enter playlist name
4. Choose visibility:
   - **Public** - Others can see it
   - **Private** - Only you can see it
5. Click **"Create"**

### Adding Songs to Playlists

**Method 1: From Songs Page (Right-Click)**
1. Go to **"Songs"** page
2. **Right-click** on any song title
3. Hover over **"Add to Playlist"**
4. Click the playlist name
5. Song is added!

**Method 2: From Queue**
1. Add songs to your queue
2. Click the **"+"** button next to a song in the queue
3. Select a playlist from the dropdown

**Method 3: From Playlist Page**
1. Open a playlist
2. Click **"Add Songs"**
3. Select songs from the list
4. Click **"Add Selected"**

### Managing Playlists

**View Playlist:**
- Click on a playlist card to see all songs

**Remove Songs:**
- Open the playlist
- Click **"Remove"** next to any song

**Delete Playlist:**
- Open the playlist
- Click **"Delete Playlist"**
- Confirm the action

## ⭐ Rating Songs

### How to Rate

1. Go to **"Songs"** page
2. Find a song you want to rate
3. Hover over the stars below the song
4. Click on a star (1-5 stars)
5. Your rating is saved instantly!

### Rating System
- ⭐ 1 Star - Poor
- ⭐⭐ 2 Stars - Below Average
- ⭐⭐⭐ 3 Stars - Average
- ⭐⭐⭐⭐ 4 Stars - Good
- ⭐⭐⭐⭐⭐ 5 Stars - Excellent

### Viewing Ratings
- **Average Rating** - Shown below each song
- **Rating Count** - Number of users who rated
- **Your Rating** - Stars are filled in gold

1. Go to **"Profile"**

   - Current password

3. See all songs you've uploaded

## 🛡️ Admin Features

*Only available to admin users*

### Access Admin Panel

1. Click **"Admin"** in the navigation menu
2. See the admin dashboard

### Manage Users

1. Go to **Admin → Users**
2. View all registered users
3. Actions:
   - **Make Admin** - Grant admin privileges
   - **Remove Admin** - Revoke admin privileges
   - **Delete User** - Remove user account

### Manage Songs

1. Go to **Admin → Songs**
2. View all uploaded songs
3. Actions:
   - **Delete Song** - Remove inappropriate content
   - View uploader information

### Manage Genres

1. Go to **Admin → Genres**
2. View all genres
3. Actions:
   - **Add Genre** - Create new genre
   - **Delete Genre** - Remove unused genre

### Review Genre Requests

1. Go to **Admin → Genre Requests**
2. See user-requested genres
3. Actions:
   - **Approve** - Add genre to system
   - **Reject** - Decline request

## 🔧 Troubleshooting

### Song Won't Play

**Check:**
- ✅ File format is supported (MP3, WAV, AAC)
- ✅ Audio data uploaded correctly
- ✅ Browser supports HTML5 audio
- ✅ Volume is not muted

**Try:**
- Refresh the page
- Clear browser cache
- Try a different browser

### Upload Failed

**Common Issues:**
- File too large (try under 10MB)
- Unsupported format
- Network connection interrupted

**Solution:**
- Check file format
- Try a smaller file
- Check internet connection
- Try again

### Can't Find a Song

**Try:**
- Check spelling in search
- Remove genre filters
- Clear search and browse all
- Song might have been deleted

### Playlist Not Showing

**Check:**
- You're logged in
- Playlist wasn't deleted
- You have permission to view it

### Rating Not Saving

**Check:**
- You're logged in
- Click directly on a star
- Wait for confirmation
- Refresh page to verify
